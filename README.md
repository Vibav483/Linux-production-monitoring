# Linux Production Monitoring & Auto-Remediation

A Linux-based monitoring and automation project built using Bash scripting.

## Project Goals

- Monitor Linux system health
- Monitor CPU and memory usage
- Monitor disk and inode utilization
- Monitor critical services
- Monitor important system logs
- Generate alerts
- Perform automated remediation
- Practice production-style Linux administration
- Version control the project using Git and GitHub

## Technologies

- Linux
- Bash
- Git
- GitHub
- systemd
- SSH
